Data Preprocessing

In this section, we prepare our raw dataset for machine learning. Real-world data is rarely clean or directly usable, so the preprocessing workflow you learn here is essential for building reliable models.

We will walk through each step of transforming the raw Ames Housing dataset into a fully usable modeling dataset. By the end of this section, you will understand not only what to do, but why each operation matters.

In this section, you will learn how to:

  1. Split the dataset into training and testing sets
    Ensuring that all preprocessing decisions are made using the training data, preventing data leakage and enabling reliable model evaluation.

  2. Identify missing values
    Quantifying where missingness occurs and determining which variables require special attention.

  3. Drop variables with excessive missingness
    Removing features that are too incomplete to be useful (e.g., more than 40% missing).

  4. Separate numerical and categorical variables
    Recognizing that different data types require different preprocessing strategies.

  5. Impute missing values
    Using appropriate techniques such as median imputation, KNN imputation, or filling categorical missing values with "None".

  6. Identify ordinal vs. nominal categorical variables
    Distinguishing between ordered category scales (e.g., quality ratings) and unordered labels (e.g., neighborhood names).

  7. Encode ordinal variables manually
    Mapping ordered categories (e.g., "Po" < "Fa" < "TA" < "Gd" < "Ex") to meaningful integers.

  8. Apply one-hot encoding to nominal variables
    Converting unordered categorical labels into binary indicator variables suitable for machine learning models.

Together, these steps form a complete and replicable preprocessing pipeline that you can apply to any structured dataset in future projects.
