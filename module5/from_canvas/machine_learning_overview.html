Overview

This module introduces students to the foundational concepts, methodologies, and practical applications of machine learning in the context of computational economics. Emphasizing both predictive and explanatory modeling, students will explore the philosophical and methodological differences between econometrics and machine learning.

The module covers key supervised learning techniques including linear models with regularization, decision trees, random forests, and gradient boosting. Additionally, students will engage with essential practices such as handling missing data, feature engineering, cross-validation, and hyperparameter tuning.

Through hands-on projects using real-world datasets (e.g., real estate data), students will build, evaluate, and refine machine learning models, developing both conceptual understanding and applied skills.

Learning Objectives

At the end of this week you should be able to: 

  • Explain the differences between explanatory and predictive modeling.

  • Identify key machine learning approaches for classification and regression.

  • Prepare data and apply feature engineering techniques for modeling.

  • Build and evaluate models using linear and tree-based algorithms.

  • Apply model validation and tuning techniques to improve performance
