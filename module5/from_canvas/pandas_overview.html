Overview

This module provides a comprehensive overview of Pandas, a crucial library in Python for data analysis. You'll learn about Pandas' fundamental data structures, with a focus on Series and DataFrames, and how to access and manipulate their elements. The course covers combining datasets and employing summary functions for dataset familiarity. You'll also gain skills in querying, grouping, sorting, and manipulating columns within datasets. Essential techniques for cleaning data are included to ensure data quality. Finally, the module introduces simple data visualization methods, enabling you to effectively represent and interpret your data analyses.

Learning Objectives

At the end of this week you should be able to: 

  1. Explain Pandas' Data Structures Series
  2. Access Series Elements 
  3. Access DataFrame Elements 
  4. Combining datasets
  5. Use the Summary functions to get familiar with the dataset
  6. query your dataset 
  7. group and sort the data 
  8. manipulate Columns 
  9. Clean the dataset 
  10. Perform simple data Visualization
